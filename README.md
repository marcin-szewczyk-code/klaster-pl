# KLASTER+

Repozytorium strony internetowej projektu **KLASTER+ – Wspólnoty energetyczne przyszłości. Projekt NdRS.**

Strona prezentuje założenia projektu, jego Zespół i partnerów, aktualności, realizowane działania oraz uzyskiwane rezultaty.

Strona projektu:

Repozytorium źródłowe:

## Technicznie

Strona została zbudowana przy użyciu:

- generatora statycznych stron Jekyll,
- motywu Chirpy,
- formatu Markdown do przygotowywania treści,
- platformy hostingowej GitHub Pages,
- mechanizmu publikacji GitHub Actions.
